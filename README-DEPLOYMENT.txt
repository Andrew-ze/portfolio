# Drew.dev Portfolio

A static, responsive, tech-styled portfolio for Andrew Ategeka.

## Files
- `index.html` — home page
- `about.html` — about page
- `skills.html` — current skills and learning areas
- `projects.html` — selected projects
- `contact.html` — contact methods
- `style.css` — shared dark tech theme
- `images/` — existing images from the original portfolio
- `assets/CV.docx` — original CV asset, preserved from the supplied archive

## Preview locally
Open `index.html` in a browser, or use VS Code's Live Server extension.

## Deploy
This is a static website. You can deploy the folder to Netlify, or push it to GitHub and enable GitHub Pages. Upload the contents of this folder (including `style.css` and `images/`) so relative paths continue to work.

## Before publishing
1. Verify that the email, phone/WhatsApp, GitHub, and LinkedIn links are correct and that you want them public.
2. Add a confirmed live demo/repository URL for each project when available.
3. Confirm permission before displaying client project details or images.
4. Keep passwords, API keys, and private configuration out of the public folder.
5. Test all pages on a phone and laptop after deployment.

This portfolio is static and does not require Node.js or MySQL to run.
